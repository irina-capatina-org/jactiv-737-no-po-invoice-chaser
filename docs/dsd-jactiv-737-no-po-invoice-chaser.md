## 1. Solution Overview

Weekday at 10:00 Romania time: queries Coupa for draft/new invoices from the past seven days, excludes credit notes, counts those with no valid PO link on any line, and sends one Block Kit Slack message to the AP SME. Zero qualifying → silent exit. No Coupa record is written.

| Project | Product | Role | Entry point |
|---|---|---|---|
| `no-po-invoice-chaser-api` | API Workflow | Primary (only) | `Workflow.json` — schedule-triggered, no caller input |

## 2. As-Built Architecture

```
Schedule (Orchestrator, weekday 10:00 Europe/Bucharest)
        │
        ▼
no-po-invoice-chaser-api
  [code/no-po-invoice-chaser-737/no-po-invoice-chaser-api/Workflow.json]
  ├── JS: compute windowStart / windowEnd / runDate
  ├── HTTP GET → uipath-coupa-coupa (coupa-uipath-test)  path: invoices
  ├── JS: filter credit notes; retain draft/new
  ├── JS: qualify invoices where any line lacks numeric po-number and order-header-num
  ├── IF count > 0:
  │     ├── JS: build coupaUrl  [OQ-04: swap uipath-test.coupahost.com for prod]
  │     └── HTTP POST → uipath-salesforce-slack (slack-product-test-app)
  └── Response per terminal path (markJobAsFailed set correctly)
```

Single TryCatch wraps the whole flow; no child workflows, queues, assets, or retry (BR-08).

## 4. Exception and Error Handling

| ID | Condition | Detected by | Action | Job state |
|---|---|---|---|---|
| S1/S2/S4 | Coupa non-200 or `.content` not array | `If_CoupaValid` in `Workflow.json` | `Response_Failed_Coupa`; `markJobAsFailed: true` | Failed |
| S3 | Slack non-200 or `.content.ok ≠ true` | `If_SlackValid` in `Workflow.json` | `Response_Failed_Slack`; `markJobAsFailed: true` | Failed |
| S5/S6 | Uncaught runtime exception | TryCatch catch in `Workflow.json` | `Response_Failed_Unhandled`; `markJobAsFailed: true` | Failed |
| B1 | `is-credit-note === true` | `Javascript_Filter` in `Workflow.json` | Excluded; not counted | — |
| B2 | PO field is description-only text | `Javascript_POLinkage` in `Workflow.json` | Treated as no-PO; counted | — |
| B3/BR-07 | `qualifyingCount === 0` | `If_CountGtZero` in `Workflow.json` | `Response_CleanDay`; no Slack call | Succeeded |
